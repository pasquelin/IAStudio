# Socle Scenario Studio — plan d'implémentation

> **Pour les agents :** utiliser `superpowers:executing-plans` pour exécuter tâche par tâche.
> Les étapes sont cochables (`- [ ]`).

**Goal :** une application Electron qui démarre, s'authentifie sur l'API Scenario, liste les
modèles, génère une image via un formulaire construit depuis le schéma du modèle, et l'indexe
dans un projet local — le squelette sur lequel les six espaces viendront se poser.

**Architecture :** trois process (main Node / preload / renderer React), contrat IPC typé dans
`shared/`. Le main détient seul la clé API, le SDK Scenario, la file de jobs et le catalogue
SQLite. Le renderer est une coquille Dockview avec un design system maison. Les moteurs
créatifs ne sont pas dans ce plan.

**Tech Stack :** Electron 43 · electron-vite 5 · React 19 · TypeScript 6 · Vite 8 ·
dockview-react 7 · Tailwind 4 · Zustand 5 · TanStack Query 5 · @scenario-labs/sdk 2 ·
better-sqlite3 13 · Vitest 4.

Spec de référence : `docs/specs/2026-08-06-scenario-studio-design.md`.

## Global Constraints

- Code, commentaires, libellés et messages **en français**, accents corrects.
- **Zéro `any`**, pas de `as const`, `type` plutôt qu'`interface`, pas de `@ts-ignore`.
- Prettier : 2 espaces, guillemets simples, **pas de point-virgule**, trailing commas,
  `printWidth` 100, `arrowParens: avoid`.
- Commentaires : aucun par défaut ; uniquement un *pourquoi* non évident, une ligne.
- Alias `@/` → `src/renderer/src/`, `@shared/` → `src/shared/`.
- `src/shared/` n'a **aucune dépendance runtime**.
- Le renderer n'a ni clé API, ni `fs`, ni `child_process`. `contextIsolation: true`,
  `nodeIntegration: false`, `sandbox: true`.
- Aucun `ipcRenderer.invoke` avec chaîne littérale hors de `preload/`.
- Tests `*.test.ts` colocalisés. Toute tâche livre ses tests.
- **Definition of done par tâche** : tests verts → `pnpm validate` → `/simplify` →
  `/code-review` → commit.

  let simultanes = 0
  let pic = 0
  const gestionnaire = creerJobManager({
    concurrence: 2,
    executer: async () => {
      pic = Math.max(pic, ++simultanes)
      await attendre(5)

## Ce que ce plan ne couvre pas

Les moteurs créatifs (`CanvasEngine`, `SceneEngine`, `TimelineEngine`, `AudioEngine`),
le multi-fenêtres et le détachement de panneaux, le `PlaybackManager`, le backend cloud,
la fenêtre de réglages complète (seul l'onglet Compte est nécessaire ici), ffmpeg et les
workers. Chacun fera l'objet de son propre plan.
