title: Step 1: Obtain Your API Key | Scenario Docs
---

Your API Key and API Secret are essential for authenticating your requests to the Scenario API. These credentials act as your unique identifier and authorization token. If you haven’t already, please follow these instructionsto obtain your API Key and Secret:

1. Go to your Organization settings.

![](https://files.readme.io/6f5a1c1f39b05865866289a3c8d649b47453097d4fd536b8a112ef3e589e9d7e-image.png)

2. Go to “API Keys”

![](https://files.readme.io/7ec1d2dec7f877c11cc7ae9f7624e0933a70d76cf3f248ac530c969bc9385655-image.png)

3. “Add API Key”

![](https://files.readme.io/abb2830d549d95bd634278e896dca65810fc7884d79e2a43873d814f1f2e7c92-image.png)

4. Follow instructions

Once you have your API Key and Secret, keep them secure and do not expose them in your client-side code or public repositories.
